## When stuck

1. Read the error message fully; identify the file and line.
2. Reproduce in the smallest possible example.
3. Check the official docs for the exact API.
4. Search the error text plus the library name.
5. Ask a precise question: what you expected, what happened, what you tried, and the minimal code.
6. If using AI, ask for a hint or a diagnosis first. Make it explain the fix, then retype it yourself.

## Job search

- Keep a spreadsheet: company, role, source, date, status, contact, next action.
- DevTrack is literally the tool for this. Use your own app once it is ready.
- Apply before you feel ready. Rejection is data, not a verdict.
